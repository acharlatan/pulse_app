# Connected PULSE — final release, part 1

This stage refines the shared shell and gives Network and profiles a relationship-first layout. Directory records are distinct surfaces, profile identity and related work have a consistent frame, and native controls remain available in light/dark and mobile layouts. No working record action or local media is replaced.

Network's selected-person context panel carries the directory's URL-backed search and filters into the full profile. A profile opened from Network returns to that directory. Profile links to scoped Analytics and Orbit offer a return to the originating profile; Orbit retains this return context when its scope is changed or reset. Review category and sort use a shareable URL; a profile opened from Review can return to that view, including through scoped Analytics or Orbit. Navigation state is not persistent CRM data and is not added to backups. Company last-conversation display excludes future conversations.

Existing repositories, restriction checks, freshness guards, database and backup formats are unchanged. Part 2 must run broader browser, offline, migration and release verification, record physical-device/native-screen-reader limits, resolve observed issues and publish after verification.
