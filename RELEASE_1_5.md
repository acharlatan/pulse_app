# PULSE 1.5 release candidate

Prompt 12 refreshes Daily Pulse with a time-aware greeting, prioritized saved tasks, relationship review, pinned identities and active opportunity context. Home task completion continues to use the existing transactional repository and progress system.

Search is local to the selected workspace and available from the shell or Ctrl/Command+K. It searches people, companies, opportunities and tasks without indexing private notes. Quick actions open existing editors and destinations. Search input is excluded from unsaved-edit tracking; actual forms remain protected. No database migration or external search service is required.

Google Calendar and Contacts remain optional; live setup still requires the user's Google configuration. Offline and backup formats remain on version 6.
