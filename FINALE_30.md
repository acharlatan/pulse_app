# PULSE finale: compact workspace, portrait Orbit and languages

The four-area shell is retained while the Home, People, Work, Insights and Orbit layouts use shorter headers and denser controls. Orbit keeps search visible, moves optional filters behind an explicit control, and puts less toolbar content ahead of the map. Existing paths, list views and record actions remain available.

Orbit's Three.js graph uses the same bounded saved records and association edges. Its portraits and company icons use the existing local-media and fictional-demo Avatar implementation; custom images stay local, and missing images fall back to initials/icons. Names are real HTML text, not scaled canvas textures. A fixed-pass visual layout separates marker controls on small displays; dotted tethers connect shifted markers to their 3D points, while solid graph lines remain the saved associations. Depth is visual, not a relationship-strength signal. The 3D map balances people, companies and opportunities when truncated: up to 12 nodes on mobile and 24 on desktop; 2D mobile supports 18 and the list up to 60. Search, filters, rotation, zoom, record selection, keyboard/list access, reduced motion and the 2D/WebGL fallback remain.

Settings and the workspace menu offer English, Spanish, French, Brazilian Portuguese, German, Italian, Indonesian, Filipino, Japanese, Korean and Simplified Chinese. Navigation, selected screen labels and common editor fields are localized; other UI content remains English, which is disclosed beside the selector. Dates and numbers follow the chosen locale. Stored names, notes, relationships and other user records are never translated. The existing per-workspace locale setting persists through reload and backup; no schema migration or external translation service is used.

No Google account, provider key, automatic outreach, synchronization, data schema or backup-format change was introduced. Automated Chromium viewport, keyboard, axe, offline and update tests complement unit tests; they are not physical-device or native-screen-reader certification.
