# Getting started with PULSE

PULSE keeps professional relationships, conversations, opportunities and follow-ups together. No account is required.

1. Open https://pulse.icareaboutyoufam.workers.dev and choose **Explore Demo** for fictional records, or **Create My Workspace** for an empty Personal workspace.
2. Follow the optional Home guide. Add a person/company, or open **Network → Import contacts**.
3. Open a profile and log a conversation or note. Plan a follow-up with the relevant person already selected.
4. Use Activity for commitments, Pipeline for opportunities, and Relationship Review for explained recommendations. Smart Lists update as your records change.
5. Optional XP starts only after enabling earning in Settings → Your momentum. Existing records are not bulk rewarded.
6. Export a JSON backup from Settings → Privacy & data. Check Downloads and store the file safely. No automatic cloud backup exists.
7. Find help again through Settings → Help & getting started. Hiding the Home guide does not delete records.

CSV: UTF-8, ≤2 MB / 2,000 rows / 40 columns. Quoted commas/newlines and BOM are supported; .xlsx is not. Map a full name or first name, then review validation and duplicates. Skip is the duplicate default. Updates require selected fields; blanks preserve existing values and permissions/restrictions are never imported. Export first: there is no separate import undo.

AI generation is disabled in the public release candidate. The interface explains selected-context approval; a separately secured backend is required for live requests. Manual reviewed email/WhatsApp drafts and calendar files remain available with compatible external apps. They do not prove delivery or synchronize accounts.
