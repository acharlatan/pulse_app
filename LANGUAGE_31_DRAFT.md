# Partial language coverage

This branch connects app-authored JSX text, selected visible attributes, enum displays and interpolated interface labels to the workspace language. Stored record values and canonical enum values are not changed. Language changes are designed to rerender an open editor without discarding its unsaved fields. User-entered names, descriptions and notes are not sent for translation.

The inventory is in `src/i18n/interface-inventory.json`; `interface-messages.json` is deliberately incomplete, and English remains the fallback for missing messages. As of this revision, 564 of 1,751 inventoried strings have entries in all ten non-English languages. Earlier wording was machine-assisted; newer common labels and selected safety messages were added directly. None has received comprehensive language-by-language review. Higher-risk unreviewed backup, deletion, consent, restriction and privacy messages were held back rather than published as potentially misleading translations. Some dynamic app-generated text, onboarding/recovery states, exports and accessibility text still need an audit. The existing in-app notice that translations are partial remains accurate.

This is a partial localization release, not full translation coverage. Further work is needed to finish the catalog, review safety-critical meanings and placeholders in every language, and inspect dynamic states. No app runtime translation service, new credentials, account connection or schema change is introduced.
